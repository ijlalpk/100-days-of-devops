# 🔥 #100DaysOfDevOps

> 100 consecutive days of learning DevOps in public — one commit, one lesson, every single day.

![Progress](https://img.shields.io/badge/Progress-Day%201%2F100-blue)
![Commitment](https://img.shields.io/badge/Commitment-Daily-brightgreen)

## The Rules

1. **Learn DevOps for at least 1 hour every day** for 100 days
2. **Log it here** — a short entry per day: what I learned, what I built, what confused me
3. **Share it** on LinkedIn with #100DaysOfDevOps
4. Missing a day is allowed for emergencies — but never two in a row

## 🗺️ The 100-Day Plan

| Phase | Days | Focus |
|---|---|---|
| 1 | 1–20 | **Linux & Bash** — commands, permissions, processes, scripting → [`linux-fundamentals`](https://github.com/ijlalpk/linux-fundamentals) |
| 2 | 21–35 | **Git & GitHub** — branching, PRs, workflows, this very portfolio |
| 3 | 36–55 | **Docker** — images, containers, volumes, networks, Compose |
| 4 | 56–80 | **Kubernetes (CKA prep)** — daily labs → [`kubernetes-labs`](https://github.com/ijlalpk/kubernetes-labs) |
| 5 | 81–95 | **Terraform & AWS** — IaC → [`terraform-aws-basics`](https://github.com/ijlalpk/terraform-aws-basics) |
| 6 | 96–100 | **CI/CD with GitHub Actions** — pipeline for a real project |
